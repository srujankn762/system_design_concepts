# Run Argo cd
kubectl port-forward svc/argocd-server -n argocd 8080:443

#kubectl port-forward creates a temporary connection from a port on your computer to a port inside Kubernetes.


#Your computer:8080  →  argocd-server service:443

  - svc/argocd-server: the Argo CD server Service
  - -n argocd: finds it in the argocd namespace
  - 8080:443: maps local port 8080 to Kubernetes port 443

Each resource has a different purpose:

  - Deployment: manages pod replicas and restarts them.
  - StatefulSet: manages stateful pods with stable identity and storage.
  - Service: provides stable networking to pods.
  - PersistentVolumeClaim: requests durable storage.
  - PersistentVolume: provides the actual storage.
